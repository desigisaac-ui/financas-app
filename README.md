# 💰 Finanças App

Aplicativo de controle de finanças pessoais do Isaac.

## Funcionalidades

- ✅ Registrar entradas e saídas
- ✅ Atribuir despesas a múltiplos meses
- ✅ Gráfico de barras: Entradas × Saídas
- ✅ Gráfico de linha: Projeção de saldo acumulado
- ✅ Categorização de despesas
- ✅ Filtro por mês
- ✅ Dados salvos no localStorage

## Como usar

Abra o arquivo `index.html` em qualquer navegador, ou acesse via GitHub Pages.

## Dados iniciais

O app vem pré-carregado com os dados da planilha "Gastos Pessoais" (abas Dia 1 e Dia 15).

## Tecnologias

- React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- Recharts (gráficos)
- Framer Motion (animações)
